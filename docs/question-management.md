# 문제 일괄 삭제와 단답형 채점

## 일괄 삭제

관리자 문제 목록에서 체크박스로 선택한 뒤 `선택한 문제 삭제`를 누른다. 현재 페이지 전체 선택과 페이지 간 선택 유지가 가능하며, 검색어·유형·능력단위 필터를 변경하면 선택을 초기화한다. 한 번에 최대 500개까지 삭제할 수 있다. 확인 창에 실제 선택한 문제 ID·제목·능력단위를 표시한다.

`DELETE /admin/questions/bulk`에 `{ "questionIds": [1, 2] }`를 전달한다. 기존 관리자 인증을 사용한다. 성공 응답은 기존 응답 래퍼의 `data`에 `deletedCount`, `alreadyDeletedCount`를 포함한다. 존재하지 않는 ID가 섞여 있으면 전체 작업을 취소한다.

삭제는 문제의 `deletedAt`을 설정한다. 관리·다운로드·출제·오답 복습 목록에서는 제외하고, 기존 문제·보기 ID와 사진·오답 횟수·제출 답안·채점 결과는 보존한다. 과거 결과 조회는 삭제된 문제도 불러온다. 엑셀 검토 후 삭제된 문제를 해당 검토로 다시 반영하려고 하면 충돌로 차단한다. 이미 삭제한 ID로 재시도해도 나머지 기록을 지우지 않는다.

업체가 보고한 중복 문제는 이 기능으로 관리자가 정확한 ID를 선택해 삭제한다. 자동 중복 판정이나 운영 데이터 삭제는 수행하지 않는다.

## 단답형

기존에는 등록한 정답 중 첫 번째만 검사했다. 이제 `SHORT_ANSWER`에 등록된 유효한 정답 중 하나와 일치하면 정답으로 인정한다. 앞뒤 공백과 영문 대소문자는 기존과 같이 무시하며, 내부 띄어쓰기·괄호·영어 표기는 관리자가 등록한 그대로 비교한다. 자동 번역·동의어 추론·괄호 제거는 하지 않는다.

예를 들어 `자재 목록표`와 `BOM`을 각각 정답 항목으로 등록하면 둘 중 하나만 입력해도 인정한다. `자재 목록표(bill of material)`만 등록하면 해당 항목 전체와 일치해야 한다. 관리자 저장 시 정답 ID가 해당 문제에 속하는지 확인하고, 정답을 전부 비우거나 존재하지 않는 ID를 전달하면 저장 전체를 취소한다. 수정한 단답형 항목은 유효한 정답으로 저장한다.

과거 채점 결과를 재계산하지 않는다. `MULTIPLE_SHORT_ANSWER`의 채점 규칙은 변경하지 않았다.
