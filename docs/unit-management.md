# 능력단위 추가와 삭제

## 추가

관리자 능력단위 목록 상단의 `능력단위 등록`을 누르면 등록 창이 열린다. 능력단위명을 입력하고 시험을 원하는 만큼 선택한 뒤 저장한다. 시험은 선택하지 않아도 등록할 수 있고, 나중에 수정 창에서 연결한다. 등록한 능력단위는 목록 최상단에 나타나며 문제 관리의 능력단위 필터와 엑셀 다운로드 단위 선택에도 바로 보인다.

`POST /admin/units`에 `{ "name": "전기설비 설계", "examIds": [1, 2] }`를 전달한다. 기존 관리자 인증을 사용한다. 능력단위명은 앞뒤 공백을 제거해 저장하고, 공백만 입력하면 저장하지 않는다. 이미 같은 이름의 능력단위가 있으면 4201로 거절한다. 존재하지 않는 시험 ID가 섞여 있으면 등록 전체를 취소한다.

## 수정

목록의 `수정`을 누르면 능력단위명과 연결 시험, 표시여부를 한 창에서 바꾼다. 저장하면 선택한 시험 목록으로 연결을 통째로 교체한다. 이름 중복 검사는 자기 자신을 제외하고 수행한다. 존재하지 않는 능력단위를 수정하려 하면 4200으로 거절한다.

기존에는 저장 응답에 연결 시험이 항상 비어서 창을 닫았다 열어야 반영을 확인할 수 있었다. 이제 저장 응답이 실제 저장된 시험 목록을 그대로 담는다.

## 삭제

목록의 `삭제`를 누르면 능력단위명과 등록된 문제 수를 보여주는 확인 창이 열린다. 문제가 한 건이라도 등록된 능력단위는 삭제할 수 없다. 이 경우 확인 창에서 삭제 버튼을 막고, 서버도 4202로 거절한다. 문제 관리에서 해당 문제를 먼저 삭제한 뒤 능력단위를 삭제한다.

`DELETE /admin/units/:unitId`를 호출한다. 삭제는 능력단위의 `deletedAt`을 설정한다. 관리자 목록과 학습자 능력단위 목록, 문제 관리의 능력단위 필터에서 모두 제외하며 기존 능력단위 ID는 보존한다. 존재하지 않는 ID로 요청하면 4200으로 거절한다.

## 문제 수

목록에 능력단위별 문제 수를 함께 보여준다. 삭제된 문제는 세지 않는다. 삭제 가능 여부를 목록에서 바로 판단하기 위한 값이며, 별도의 통계나 집계 화면은 제공하지 않는다.
