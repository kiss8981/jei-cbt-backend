# V3 첨부 양식 검증 결과

검사 파일: `템플릿_V3_문제_1776153685375.xlsx`

총 6,053개 문제 행 중 6,034행은 형식 검사를 통과했고 19행에서 아래 오류를 발견했다. 원본 파일은 수정하지 않았다. 실제 업로드 화면에서도 같은 시트명과 엑셀 행 번호로 오류를 표시하며, 오류를 고치기 전에는 전체 반영을 차단한다.

| 시트 | 엑셀 행 번호 | 검사 결과 |
| --- | --- | --- |
| MULTIPLE_CHOICE_INPUT | 172 | 보기와 정답 여부의 줄 수 불일치 |
| MULTIPLE_CHOICE_INPUT | 259, 272, 281, 794, 810, 834 | 답안 항목에 빈 줄 또는 빈 값 |
| MULTIPLE_CHOICE | 172 | 보기와 정답 여부의 줄 수 불일치 |
| MULTIPLE_CHOICE | 259, 272, 281, 794, 810, 834 | 답안 항목에 빈 줄 또는 빈 값 |
| MATCHING | 86, 90 | 답안 항목에 빈 줄 또는 빈 값 |
| MULTIPLE_SHORT_ANSWER | 102, 104, 106 | 답안 항목에 빈 줄 또는 빈 값 |

격리된 MySQL 테스트에서는 오류가 있는 원본 파일의 전체 반영 차단을 확인했다. 이어 유효한 6,034행만 테스트 DB 내부에서 분리해 저장·다운로드·재검사했고, 다시 내려받은 문제는 모두 변경 없이 인식됐다. 실제 서비스 API는 일부 행 반영을 허용하지 않는다.

이 검사는 파일 구조와 입력 형식을 확인한다. 문제 내용이나 정답의 지식상 타당성을 검수한 결과는 아니다.
